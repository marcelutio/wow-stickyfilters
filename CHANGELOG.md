# Changelog

## 1.2.0

- EllesmereUI merchant skin: colors, dimming, icons, search highlight and tooltips also work in its "Show As List" and expanded vendor views; the page hint follows the expanded view's page size
- EllesmereUI: search boxes, filter buttons and hint boxes use the EllesmereUI look through its skinning API (can be turned off in EllesmereUI under third-party addon skins)
- MerchantPlus: its list tab gets the same colors, dimming, icons and tooltip lines; the whole row is tinted in the item's color (option); icons are 25% smaller there
- Buyback tab: colors, dimming, filters, search, icons and tooltip lines work there too
- Coin and check mark icons sit half outside the item icon on merchant tiles
- Dimmed purple (epic) item names are easier to read
- Tooltip wording names the green check mark and the green search animation explicitly
- Colors and icons refresh when money, bags or learned recipes change while the merchant is open

## 1.1.0

- Quest rewards in the quest log preview and at the quest giver (accept and turn in) use the merchant colors and the green check mark
- Short explanations in the reward tooltip, also in addons that replace the quest window (for example Immersion)
- New options page "Quest rewards"
- Trainer: "Skill missing" is shown by default, so the profession range filter is not hidden by it (applied once to existing settings)

## 1.0.1

- Hint text uses neutral wording and names the full options path
- Page hint only appears for an active search, not for range or category filters alone
- Dimmed rows are a bit more visible (20% opacity), their coin and check mark icons 40%, trainer prices and requirement lines 30%

## 1.0.0

First public release for World of Warcraft: Forever.

- Persistent trainer filters and "Categorize", enforced against changes by other addons
- Color coding for trainer entries and merchant items by reason
- Crossed-out currency icon for unaffordable items (gold and other currencies)
- Green "fits me" check mark (class, race, gear, recipes for your professions)
- Fuzzy search with highlight and page hint, category filters, level and profession windows
- Tooltip lines "Missing" / "After buy" plus short explanations
- Own search box and filter menu for merchants and trainers
- Remembered search text, per NPC (default) or global, and a one-time hint with arrow for the new controls
- `/sf icons` to toggle the coin and check mark icons, `/sf reset` for defaults
- Settings page under Options > AddOns with tooltips and examples (general, merchant and trainer pages)
- English and German, selectable in the options
